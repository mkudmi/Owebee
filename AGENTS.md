# Инструкции для агентов

## Язык общения

- Всегда отвечай пользователю на русском языке.
- Сохраняй исходное написание идентификаторов, команд, путей, логов, API и цитат, если перевод снижает техническую точность.
- Документы проекта создавай на русском языке, если пользователь явно не попросил другой язык.

## Python и BMAD

- Для запуска скриптов из `_bmad/scripts` используй `uv run`.
- При прямом запуске через `python3` используй Python 3.11 или новее.
- `tomllib` входит в стандартную библиотеку Python 3.11+; не устанавливай отдельный пакет `tomllib`.

## SDD и фиксация прогресса

- Разрабатывай по SDD (Spec-Driven Development): перед реализацией сверяйся с актуальными требованиями и контрактами в PRD, архитектуре, UX-документах и соответствующей story. Если задача меняет требования или поведение, сначала зафиксируй это в спецификации/story, затем меняй код.
- По мере выполнения обновляй документы вместе с реализацией: отмечай выполненные задачи, решения и результаты проверок в story; поддерживай фактические статусы в `_bmad-output/implementation-artifacts/sprint-status.yaml`.
- При изменении объёма, порядка или сроков обновляй соответствующий sprint plan; отложенную работу фиксируй в `_bmad-output/implementation-artifacts/deferred-work.md` или в story. Не отмечай задачу завершённой без проверенного результата.
